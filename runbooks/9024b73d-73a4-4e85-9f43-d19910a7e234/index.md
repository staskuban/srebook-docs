## Установка расширения srebook для VS Code из VSIX файла

Пошаговое руководство по ручной установке плагина srebook в редактор Visual Studio Code с использованием предварительно скачанного пакета расширения.

---

**Аудитория:** Разработчики и IT-специалисты базового уровня

**Уровень сложности:** Начальный

### Цель

Успешная установка и активация расширения srebook в редакторе Visual Studio Code из локального файла .vsix

### Предварительные требования

**Обязательные:**
- **Visual Studio Code:** Установленная последняя стабильная версия редактора
- **Файл расширения .vsix:** Локально сохраненный файл плагина
- **Права доступа:** Права на запуск и изменение конфигурации VS Code

### Шаги выполнения

#### Шаг 1: Скачивание файла расширения

Перейдите на официальный портал и загрузите пакет установки.

*Пример:* https://portal.srebook.tech/download

> 💡 **Заметка:** Авторизация на портале не требуется.

#### Шаг 2: Открытие раздела расширений

Запустите VS Code и перейдите в меню управления расширениями.

```
Ctrl+Shift+X
```

> 💡 **Заметка:** Также можно нажать на иконку 'Extensions' в левой боковой панели.

#### Шаг 3: Запуск установки из файла

Используйте встроенную функцию импорта VSIX пакетов.

*Пример:* Меню '...' -> 'Install from VSIX...'

> 💡 **Заметка:** Кнопка с тремя точками находится в верхней части панели расширений.

#### Шаг 4: Выбор и установка файла

Выберите скачанный ранее файл в проводнике вашей ОС.

*Пример:* srebook-extension.vsix

> 💡 **Заметка:** После выбора нажмите кнопку 'Install'.

### Проверка результата

1. **Перезагрузка интерфейса**
   - Ожидаемый результат: После установки нажата кнопка 'Reload Required' или выполнена команда 'Developer: Reload Window'.

2. **Проверка иконки на Activity Bar**
   - Ожидаемый результат: На левой боковой панели появился логотип srebook.

3. **Проверка статуса в списке расширений**
   - Ожидаемый результат: Плагин srebook отображается как 'Enabled'.

### Решение проблем

**Проблема:** Ошибка 'Incompatible extension'
**Решение:** Обновите Visual Studio Code до последней актуальной версии.

**Проблема:** Иконка плагина не появилась после установки
**Решение:** Выполните принудительную перезагрузку окна через Command Palette (Ctrl+Shift+P) -> Developer: Reload Window.

**Проблема:** Любой сбой в процессе установки
**Решение:** Удалите расширение через интерфейс VS Code, перезапустите редактор и повторите установку заново.

### Примеры

#### Очистка данных

После подтверждения успешной установки файл .vsix можно удалить.

```
rm srebook-extension.vsix
```

### Лучшие практики

- Всегда используйте последнюю версию VS Code для корректной работы расширения
- Не пытайтесь установить расширение двойным кликом по файлу в проводнике ОС, используйте только меню 'Install from VSIX' внутри редактора
- При обновлении плагина просто установите новый VSIX файл поверх старого
