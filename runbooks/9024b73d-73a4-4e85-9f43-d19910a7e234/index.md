## Установка расширения srebook для VS Code из VSIX файла

Пошаговое руководство по ручной установке плагина srebook в редактор Visual Studio Code с использованием предварительно скачанного пакета расширения.

**Audience:** Разработчики и IT-специалисты базового уровня

**Difficulty:** beginner

### Goal

Успешная установка и активация расширения srebook в редакторе Visual Studio Code из локального файла .vsix

### Prerequisites

- **Visual Studio Code:** Установленная последняя стабильная версия редактора
- **Файл расширения .vsix:** Локально сохраненный файл плагина
- **Права доступа:** Права на запуск и изменение конфигурации VS Code

### Steps

#### Step 1: Скачивание файла расширения

Перейдите на официальный портал и загрузите пакет установки.

*Example:* https://portal.srebook.tech/download

> **Note:** Авторизация на портале не требуется.

#### Step 2: Открытие раздела расширений

Запустите VS Code и перейдите в меню управления расширениями.

```
Ctrl+Shift+X
```

> **Note:** Также можно нажать на иконку 'Extensions' в левой боковой панели.

#### Step 3: Запуск установки из файла

Используйте встроенную функцию импорта VSIX пакетов.

*Example:* Меню '...' -> 'Install from VSIX...'

> **Note:** Кнопка с тремя точками находится в верхней части панели расширений.

#### Step 4: Выбор и установка файла

Выберите скачанный ранее файл в проводнике вашей ОС.

*Example:* srebook-extension.vsix

> **Note:** После выбора нажмите кнопку 'Install'.

### Validation

1. **Перезагрузка интерфейса**
   - Expected: После установки нажата кнопка 'Reload Required' или выполнена команда 'Developer: Reload Window'.

2. **Проверка иконки на Activity Bar**
   - Expected: На левой боковой панели появился логотип srebook.

3. **Проверка статуса в списке расширений**
   - Expected: Плагин srebook отображается как 'Enabled'.

### Troubleshooting

**Issue:** Ошибка 'Incompatible extension'
**Solution:** Обновите Visual Studio Code до последней актуальной версии.

**Issue:** Иконка плагина не появилась после установки
**Solution:** Выполните принудительную перезагрузку окна через Command Palette (Ctrl+Shift+P) -> Developer: Reload Window.

**Issue:** Любой сбой в процессе установки
**Solution:** Удалите расширение через интерфейс VS Code, перезапустите редактор и повторите установку заново.

### Best Practices

- Всегда используйте последнюю версию VS Code для корректной работы расширения
- Не пытайтесь установить расширение двойным кликом по файлу в проводнике ОС, используйте только меню 'Install from VSIX' внутри редактора
- При обновлении плагина просто установите новый VSIX файл поверх старого
